# selflabs.org

Landing page institucional do Self-Labs. Astro estático, bilíngue, servido pelo
Cloudflare Workers no apex de `selflabs.org`.

```bash
npm install
npm run dev      # http://localhost:4321
npm run verify   # typecheck + testes de conteúdo
npm run build    # gera marca, números, site, bitmaps e cabeçalhos
```

Toda a documentação do projeto está em [CLAUDE.md](./CLAUDE.md): stack, estrutura
de pastas, regras de escrita, decisões de design, autoria dos projetos e deploy.
