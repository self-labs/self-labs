# Self-Labs, landing page

Institutional landing page for Self-Labs, published on the apex of `selflabs.org`.
This file is the single source of truth for anyone, human or agent, working in this repo.

## What this is

A static, bilingual, single-page site presenting Gustavo Cateim's engineering
portfolio: nineteen projects, five engineering principles drawn from the code
itself, and four proof numbers pulled live from the GitHub API.

Two routes only: `/` (Portuguese) and `/en/` (English). Same page, same section
order, different locale.

## Stack

| Layer      | Choice                              | Why                                                                 |
| ---------- | ----------------------------------- | ------------------------------------------------------------------- |
| Framework  | Astro 5, `output: 'static'`         | Ships zero JS by default. No runtime, no server.                    |
| Content    | Content Collections + Zod           | Adding a project is a JSON file, never a layout edit.               |
| i18n       | Astro native i18n                   | `/` is pt, `/en` is en. No automatic redirect by `Accept-Language`. |
| Fonts      | `@fontsource-variable/*`            | Self-hosted WOFF2. No runtime CDN, ever.                            |
| Hosting    | Cloudflare Workers Static Assets    | Worker with no `main`: it only serves files.                        |
| Versioning | CalVer `YYYY.M.R` in `package.json` | Shown in the footer.                                                |

## Commands

```bash
npm run dev        # dev server on :4321
npm run build      # brand assets -> stats -> astro build -> bitmaps
npm run preview    # serve dist/ locally
npm run check      # astro check (typecheck)
npm test           # content rules (node:test, no framework)
npm run verify     # check + test, what CI runs before building
npm run brand      # regenerate brand SVGs from the CorelDRAW export
npm run deploy     # wrangler deploy (CI does this; you normally do not)
```

Windows is IDE only. Nothing here needs a local server, database or container.

## Layout

```
scripts/
  build-brand.mjs   Derives isotipo/wordmark/lockup/favicon from selflabs-source.svg
  fetch-stats.mjs   Reads the GitHub API into src/data/stats.json
  build-og.mjs      Renders og.png, app icons and favicon.ico from the SVGs
src/
  assets/brand/     selflabs-source.svg is the CorelDRAW export. Never hand-edit it.
                    The other SVGs here are GENERATED. Edit the script, not the output.
  components/       One component per section, plus Trilha (the PCB rail) and CardProjeto
  content/projects/ Nineteen JSON files, one per project, both languages inside
  data/stats.json   GENERATED by fetch-stats.mjs. Committed on purpose: it is the
                    fallback when the API is unreachable during a build.
  i18n/ui.ts        Every interface string, both languages
  i18n/contato.ts   Contact channels. WHATSAPP is empty until a number is set.
  layouts/Base.astro  Head, header, rail, footer
  styles/app.css    Tokens and base. The only global stylesheet.
tests/              Editorial and structural rules
```

## Writing rules, non negotiable

These are enforced by `npm test`, which runs in CI before every deploy.

1. **Never mention BRFarma**, pharmacies, drugstores or medication. The owner
   removed that project from scope. `tests/conteudo.test.mjs` fails the build if
   the words reappear anywhere under `src/` or `scripts/`.
2. **No em dash (—) and no en dash (–)**, in any language, anywhere: copy, code
   comments, commit messages, PR bodies. Use a comma, a colon, parentheses, or a
   new sentence.
3. Portuguese with complete and correct diacritics. English that reads native,
   not translated.
4. No agency jargon. No emoji in page content.
5. Every claim must trace to something real in a repository. No invented numbers.

## The four proof numbers are derived, never typed

- `commits` and `prsExternos`: `scripts/fetch-stats.mjs` against the GitHub API.
- systems in production: counted from the project files that have a
  `selflabs.org` link and a production status. It cannot drift from the showcase.
- months of operation: computed from the oldest public repository to build date.

`.github/workflows/stats.yml` re-reads them every Monday and commits only when a
value actually changed. That commit triggers the deploy workflow.

If the API fails, `fetch-stats.mjs` keeps the committed file and exits 0. A stale
number on the page beats a build broken at three in the morning by a 502.

## Design decisions worth knowing before changing CSS

- **Dark only, on purpose.** The five brand trace colours sit between 1.45:1 and
  1.58:1 against white, so they are unusable as text on a light background.
- **`body` uses `overflow-x: clip`, not `hidden`.** `hidden` turns the body into a
  scroll container, which silently kills `scroll-behavior: smooth` on `html` and
  makes every anchor jump. This already happened once.
- **Anchor navigation is animated in JS**, in `Trilha.astro`, because native
  smooth scrolling is ignored by several browsers and by every automated one.
  It reads `scroll-padding-top` so its destination is exactly the CSS snap point.
- **`--folga-ancora` is the single source** for the sticky header offset. CSS and
  the navigation script both read it. Changing it in one place is enough.
- **Scroll snap is `proximity`, never `mandatory`.** With `mandatory`, the
  nineteen card grid would trap a reader in its first screen.
- Centre things geometrically (`display: grid; place-content: center`) rather
  than with `50% + translate(-50%)`, which lands on half pixels inside bordered
  boxes.

## Brand assets

`src/assets/brand/selflabs-source.svg` is the raw CorelDRAW export and the only
hand authored file. Everything else is generated by `npm run brand`.

The source carries a background rect and a viewBox that does not start at the
origin (roughly `4313 1775 8723 11231`). Any script reusing those paths inside a
new viewBox must subtract `minX`/`minY` first, otherwise the drawing lands
outside the frame. `build-og.mjs` has an `encaixar()` helper for exactly this.

Palette, sampled from the artwork: `#20292E` petrol, `#0BE4EB` cyan, `#10E8D2`,
`#2CEBCE`, `#3AF2A8` mint, `#4BED9B` green.

## Deploy

Push to `master` → GitHub Actions runs `check`, `test`, `build` → `wrangler
deploy` publishes the Worker → a curl check confirms the apex returns 200.

Required repository secrets: `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`.

The `selflabs.org` zone already carries 38 subdomains pointing at homelab and VPS
tunnels. This site takes the apex and `www`, and touches nothing else.

## Contact channels

Both live in `src/i18n/contato.ts`, kept apart from `ui.ts` because they are data,
not copy: they change value without changing language.

- Email `contato@selflabs.org`, routed through Cloudflare Email Routing on the zone.
- WhatsApp, a personal number, which is why its button carries secondary weight
  while email stays the primary channel.

If `WHATSAPP` is ever emptied, the button disappears instead of rendering a broken
link. Keep that behaviour: a wrong phone link sends visitors to a stranger.

There is deliberately no contact form. A form would need an endpoint, would store
what people write, would attract spam, and would produce the same email the link
already produces. It would be the only part of the site contradicting the section
next to it.
